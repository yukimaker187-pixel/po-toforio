02 / PROBLEM

課題

化粧品LPは競合が多く、成分やスペックの羅列では差別化できない。「使った後の自分」を想像させる世界観の構築と、購入ボタンまでの自然な導線設計が課題だった。

03 / APPROACH

設計の意図

  • ファーストビューで世界観を伝え、スクロールに沿って「共感 → 成分の裏付け → 使用感 → 価格・オファー」の順に不安を解消していく王道構成。
  • トンマナは、黒に近いワイン色(#120608系)を基調にゴールド(#d4b878)とワインレッド(#c01a28)を差し色として使用し、パリの高級ブランドを想起させる重厚感と上質さを両立。見出しはCinzel/Shippori Minchoで気品を、本文はNoto Sans JPで読みやすさを担保。
04 / DETAIL

工夫した点

  • デザイン面: 商品写真やモデル写真はradial-gradientでマスキングして輪郭を背景に溶け込ませ、リボン状の光の装飾をゆっくりドリフトさせることで、静止した物撮り感を消して奥行きと高級感を演出。ゴールド(#d4b878)とワインレッド(#c01a28)を差し色に、Cinzel / Cormorant Garamond / Shippori Minchoを使い分け、欧文と和文のバランスを取りながらハイブランドらしいトンマナにまとめた。
  • 実装面: スクロール誘導の矢印、瞬く光の粒子、フローティングする商品画像などにそれぞれ異なるCSSアニメーションを持たせ、ページ全体に静と動のリズムを作った。CTAボタンの配色はcolor-mix()でアクセントカラーから自動生成して管理コストを抑え、レビューの星評価は★の重なりで小数点評価(4.5など)を再現するなど、細部の説得力にもこだわった。
05 / OUTCOME

成果 / 学び

自主制作のため数値成果はないが、この制作を通じて化粧品・美容系LPの構成テンプレートを確立。同ジャンルの案件では構成提案から最短4日で着手可能。
