PORTFOLIO

ポートフォリオ制作(動画クリエイター向け)

代表作にすぐたどり着ける構成で、作品そのものに語らせる。

01 / OVERVIEW

概要

種別
ポートフォリオサイト
想定クライアント
ペット(犬)専門の動画クリエイター
担当範囲
構成・デザイン・実装
02 / PROBLEM

課題

動画クリエイターのポートフォリオは「作品がすぐ見られること」が命。読み込みが重い、作品にたどり着くまでが長い、では逆効果になる。

03 / APPROACH

設計の意図

  • ファーストビューから代表作にすぐアクセスできる構成。
  • わんちゃんの魅力(=クライアントの作風)がサイト全体のトーンから伝わるよう、配色・余白・写真の見せ方を設計。
04 / DETAIL

工夫した点

  • SNS(Instagram/TikTok等)への導線を明確にし、サイトを「ハブ」として機能させる設計。
05 / OUTCOME

成果 / 学び

クリエイター向けポートフォリオの制作フローを確立。「作品を最も良く見せる器」としてのサイト設計はジャンルを問わず応用可能。
